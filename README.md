# Eden27

**A full-featured wedding website with guest registration, VIP verification, and event management.**

Live: [eden27.vercel.app](https://eden27.vercel.app)

---

## What It Does

Eden27 is a bespoke wedding website that handles everything guests need — from RSVP registration to event schedules, dress code, travel info, and an admin check-in system. Built with a beautiful animated UI and complete guest management backend.

---

## Features

- **Animated Hero** — auto-sliding photo carousel with smooth transitions
- **Guest Registration** — full RSVP form with plus-one support and event selection
- **VIP Verification** — API endpoint to verify VIP guest status
- **Admin Check-in Panel** — real-time guest check-in management for event staff
- **Multi-page Experience** — Schedule, Gallery, Story, FAQ, Travel, Dress Code, Registry
- **Mobile Responsive** — optimised for phones (most guests RSVP on mobile)

---

## Tech Stack

| Layer | Tech |
|-------|------|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS + Cormorant Garamond (Google Fonts) |
| Animations | Framer Motion |
| Forms | React Hook Form + Zod validation |
| Deployed | Vercel |
